# Phone PC Remote — closed Alpha test brief

Install through Google Play's closed Alpha invitation, not the GitHub APK. Remain opted in continuously for at least 14 days. Please use the app repeatedly and report actual results; installs alone are not a useful test. Never leave a paid public review as part of this test.

## Equipment and setup

An Android 8+ phone and a Windows 11 PC on a mutually reachable local network are needed for PC control. The free [Windows companion](https://apps.microsoft.com/detail/9NP7CKV77CRK) is already available. Ubuntu, compatible LG/Samsung TVs, and an Android phone with an IR transmitter are optional additional coverage; report unavailable equipment rather than marking those tests passed. Windows webcam and Bluetooth control are not supported.

## Free Pro access through Play license testing

The publisher must add each tester's Google Play account email to Play Console's license-testing list as well as grant closed Alpha access. Closed-track membership alone does NOT make purchases free. A provider's Google Group is sufficient for track access but does not replace individual license-tester emails.

Use the invited account to install from Play. In Settings, select the one-time Pro unlock. Proceed only if the Google purchase sheet offers the **test payment instrument** (for example, Test card, always approves). If an ordinary card or a real charge appears, cancel and contact the publisher. Never send passwords or payment-card information.

This exercises the actual purchase verifier, not a public bypass. Confirm that Pro becomes active. If it does not, report the displayed error without sharing purchase tokens. The publisher must validate this flow before asking the whole cohort to use it.

## Test checklist

- Pair by desktop QR, control keyboard/trackpad, and reconnect after app restart, Wi-Fi interruption and desktop restart.
- Exercise media, browser, work and presentation panels; custom buttons; home-screen actions; and supported sending-to-PC features.
- Verify names remain readable, repeated discovery does not duplicate the same device, and the latest address/port is shown after an endpoint change.
- On available LG/Samsung TVs: connect, reconnect, power/wake, and report model/firmware. On IR-capable phones: manually confirm a matching profile and test supported buttons. Do not assume all TV models support network wake or all Android phones have IR.
- Verify Pro after closing/reopening the app and while offline after a successful activation.
- Back up anything important before reinstalling. Reinstall from Play using the same account, then Restore purchases. Also test restoration on a second Android phone using that account if available. Record actual results; these are launch gates, not assumed passing.
- With a designated billing QA tester: cancellation, declined/pending test payments, acknowledgement, and revocation. The publisher must coordinate revocation separately; do not revoke the full cohort during the functionality test.
- Check the chosen language, layout, permission explanations and errors.

## Feedback

Report app version, Android/PC versions, device models, steps, expected/actual results, and whether the issue reproduces. Send feedback to the publisher's designated channel or [GitHub issues](https://github.com/nilsenj/phone-pc-remote-releases/issues). Remove QR codes, pairing credentials, purchase tokens, private files and private network information from public reports.

Production access is decided by Google after testing; no service can guarantee it. GitHub installs do not count toward the Play closed-test requirement.
